# Wash&Go

## Состав группы

Бровко Никита (github: nikbrovko)

## Идея компании

Wash&Go занимается установкой роботизированных автомоек в Москве и Московской области. Основные клиенты - автовладельцы, которым важно быстро помыть машину без записи и без лишнего ожидания.

## Разделение обязанностей

Бровко Никита - анализ конкурентов и выбор районов для первых точек.

## Что сделано

В проекте собраны данные по автомойкам и районам Москвы. После запуска программа считает рейтинг районов, строит графики, оценивает простую юнит-экономику первой точки и сохраняет короткий отчет.

Используются простые темы из курса:

- статический парсинг сайта;
- API-запрос к открытому источнику;
- обработка таблиц через pandas;
- графики через matplotlib;
- простая проверка идеи по двум группам районов;
- расчет простой юнит-экономики точки.

## Источники

- PortalWash: адреса сети роботизированных автомоек.
- OpenStreetMap Overpass API: автомойки в Москве.
- Wikipedia: население и площадь районов Москвы.
- Ручная таблица кандидатов: выбранные районы и простые оценки трафика/аренды.

Подробнее: `docs/data_sources.md`.

## Как запустить

Создать окружение и поставить библиотеки:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запустить весь проект:

```bash
python main.py
```

Только собрать данные:

```bash
python main.py collect
```

Только пересчитать анализ по уже собранным данным:

```bash
python main.py analyze
```

## Структура

- `main.py` - запуск проекта.
- `src/collect_data.py` - сбор данных.
- `src/analysis.py` - расчет рейтинга, графики и юнит-экономика.
- `data/input/` - исходная ручная таблица кандидатов.
- `data/raw/` - собранные сырые данные.
- `data/processed/` - итоговые таблицы.
- `figures/` - графики.
- `docs/` - описание данных, логики и результатов.

## Результат

После запуска появляются:

- `data/processed/location_scores.csv`;
- `data/processed/stat_summary.csv`;
- `data/processed/unit_economics.csv`;
- `figures/top_locations.png`;
- `figures/competition_by_district.png`;
- `figures/demand_vs_competition.png`;
- `figures/unit_economics_profit.png`;

Итоговый вывод: первую точку лучше выбирать среди районов с высокой плотностью населения, нормальным автомобильным трафиком, приемлемой арендой и экономикой, которая окупает запуск за разумный срок.
