# Как работает анализ

Проект сравнивает несколько районов Москвы, где можно открыть роботизированную автомойку Wash&Go.

Логика простая:

1. Берём список районов-кандидатов из `data/input/candidate_places.csv`.
2. Парсим адреса PortalWash как пример прямого конкурента.
3. Забираем автомойки из OpenStreetMap через Overpass API.
4. Для каждой точки считаем конкурентов рядом в радиусе 3 км.
5. Считаем плотность населения района.
6. Собираем итоговый балл из спроса, трафика, аренды и конкуренции.
7. Для лидеров считаем простую юнит-экономику точки.

Формула рейтинга:

`0.35 * плотность + 0.30 * трафик + 0.15 * аренда + 0.20 * конкуренция`

Все показатели перед этим переводятся в шкалу от 0 до 1. У конкуренции и аренды обратная логика: чем меньше, тем лучше.

Юнит-экономика считается отдельно. В ней используются средний чек, переменная стоимость одной мойки, ожидаемые мойки в день, аренда, обслуживание, платеж за оборудование и локальное продвижение.

Итоговые файлы появляются после запуска:

- `data/raw/portal_addresses.csv`
- `data/raw/osm_car_washes.csv`
- `data/processed/location_scores.csv`
- `data/processed/stat_summary.csv`
- `data/processed/unit_economics.csv`
- `figures/top_locations.png`
- `figures/competition_by_district.png`
- `figures/demand_vs_competition.png`
- `figures/unit_economics_profit.png`
- `docs/analysis_results.md`
