# Источники данных

## PortalWash

Сайт: https://portalwash.ru/adress

Используется статический парсинг страницы с адресами сети роботизированных автомоек. Из него получается список существующих точек похожего формата.

## OpenStreetMap

Сервис: https://overpass-api.de/

Через Overpass API выгружаются объекты `amenity=car_wash` в границах Москвы и ближайших районов. Эти данные используются как список конкурентов.

## Районы Москвы

Страница: https://ru.wikipedia.org/wiki/Районы_Москвы

Из неё взяты численность населения и площадь районов. Для проекта этого хватает как грубой оценки потенциального спроса.

## Ручная таблица кандидатов

Файл: `data/input/candidate_places.csv`

В таблицу внесены районы и примерные точки, где можно рассмотреть первую мойку. Оценка трафика и аренды сделана по простой шкале от 1 до 10/индексу, поэтому расчеты остаются понятными и воспроизводимыми.

## Допущения для юнит-экономики

Файл: `data/input/unit_economics_assumptions.csv`

В таблице лежат простые бизнес-допущения: средний чек, переменная стоимость одной мойки, аренда, обслуживание, платеж за оборудование, продвижение и первичные вложения. По ним считается понятная оценка выручки, прибыли и окупаемости.
