# План презентации

## 1. Идея

Wash&Go устанавливает роботизированные автомойки в Москве и Московской области. Основная идея: быстро помыть машину без записи и без выхода из автомобиля.

## 2. Задача анализа

Нужно выбрать районы, где первая точка будет выглядеть наиболее разумно: достаточно спроса, заметный автомобильный поток и не слишком высокая конкуренция рядом.

## 3. Источники

- PortalWash: адреса похожей сети.
- OpenStreetMap: список автомоек.
- Районы Москвы: население и площадь.
- Ручная таблица кандидатов: точки и простые оценки трафика/аренды.

## 4. Метод

Для каждого района считаются:

- плотность населения;
- конкуренты рядом;
- оценка автомобильного трафика;
- относительная аренда.

После этого строится общий рейтинг.

## 5. Графики

- топ районов по итоговому баллу;
- количество конкурентов;
- связь плотности населения и конкуренции.
- прибыль и окупаемость первой точки.

## 6. Юнит-экономика

Для лидирующих районов считается простой расчет: ожидаемые мойки в день, выручка, переменные расходы, фиксированные расходы, прибыль и срок окупаемости.

## 7. Вывод

Лучшие районы стоит выбирать не только по населению. Нужен баланс: плотный район, нормальный трафик, приемлемая аренда, конкуренция и понятная экономика первой точки.
